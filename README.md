# Christ the King Community Church

A responsive, multi-page redesign concept for Christ the King Community Church in Stoughton, Wisconsin.

## Design direction
- Heritage-inspired identity drawn from the church's historic brick building.
- Warm ivory surfaces, burgundy, charcoal, and restrained antique-gold details.
- Serif display typography paired with readable sans-serif body text.
- Responsive navigation and layouts for phone, tablet, and desktop.

## Pages
Home, About, Leadership & Spouses, History, Building, Pastors, Sermon Videos, Upcoming Events, Contact, Statement of Faith, Calendar, Stick Figure Theology, MPact Girls, Power Hour, Royal Rangers, and the existing community-resource route.

## Run locally
This is a static website. Serve this directory with any static HTTP server. Vercel rewrites clean paths to index.html; the application selects the content according to the URL pathname.

## Content integrity
The original church website is the source for text, images, and documents. Current event/calendar data and the worship schedule need confirmation by the church; this concept does not invent those details. Several older leadership biographies are explicitly flagged for role verification.

## Assets
The site references existing image and PDF files on the church's current website so original photography and forms remain tied to the source. Confirm permission and availability before a public production launch.
